# claude-code-setup

Todo el setup de Claude Code: **26 plugins**, **176 skills** y **4 MCP servers**.

## Instalación en 1 comando

```bash
git clone https://github.com/nachomdna7310/claude-code-setup.git
cd claude-code-setup
bash install.sh
```

Después reiniciá Claude Code.

Paso a paso, links y detalles: **[INSTALL.md](INSTALL.md)**
Prompt para pegarle a tu Claude: **[PROMPT.md](PROMPT.md)**

## Qué trae

- **Plugins oficiales**: superpowers, feature-dev, pr-review-toolkit, hookify, skill-creator, frontend-design, security-guidance, claude-md-management, commit-commands, session-report, claude-code-setup + 7 LSPs.
- **Plugins comunidad**: the-architect, ponytail, ui-ux-pro-max, ruflo-core, claude-mem, addy agent-skills, document-skills.
- **170 skills** en `skills/`: game dev completo, diseño/animación, backend y testing por lenguaje, seguridad, research, graphify, ECC.
- **6 skills como repos git** (gstack, humanizalo, claude-webkit, claude-banana, skill-vault, whatsapp-agentkit).
- **MCP**: chrome-devtools, playwright, context7, firecrawl.

## Notas

- No hay ninguna API key en este repo. Firecrawl necesita la tuya (https://firecrawl.dev).
- De ruflo instalar **solo `ruflo-core`**: los sub-plugins de trading ejecutan operaciones financieras reales.
